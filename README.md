# MIXDM — Download Manager ฟรี ทางเลือกแทน IDM

MIXDM คือโปรแกรมจัดการการดาวน์โหลดที่ทำงานคล้าย IDM
ใช้งานได้ฟรี ไม่มีค่าใช้จ่ายเริ่มต้น

## ✨ จุดเด่น
- ใช้งานฟรี ไม่ต้องจ่ายเพื่อเริ่มต้น
- เร่งความเร็วดาวน์โหลดด้วย multi-thread
- ทำงานร่วมกับ Chrome ผ่าน Extension
- ราคาถูกที่สุดเริ่มต้นเพียง 39 บาท/เดือน

## 💰 ราคา

| แผน | ราคา | เต็มสปีด | ความเร็วหลังหมดโควต้า |
|------|-------|-----------|----------------------|
| Free | ฟรี | 8 ครั้ง/วัน (รีเซ็ตทุกวัน) | 10 MB/s |
| รายเดือน | 39 บาท/เดือน | 50 ครั้ง/วัน | 10 MB/s |
| รายปี | 299 บาท/ปี | 100 ครั้ง/วัน | 15 MB/s |
| ตลอดชีวิต | 599 บาท (ครั้งเดียว) | 250 ครั้ง/วัน | 15 MB/s |
